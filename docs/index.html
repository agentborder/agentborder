Why trust it
Verify, do not trust. Every release is published from CI with npm provenance, so the package is cryptographically tied to this repo and commit. Run npm audit signatures. Zero runtime dependencies, tested on Linux, macOS and Windows.
No claim without proof. A User-Agent is a claim, never labeled verified without a cryptographic signature. The core ships a working Web Bot Auth verifier (RFC 9421, Ed25519).
Fail open, always. Any error inside the gate lets the request through. Breaking your site is the one thing it is not allowed to do. Apache-2.0.

The report
One command reads the access log you already have and prints a report: humans versus bots, every bot by name and category, bytes and peak requests per minute, and how many requests violated your robots.txt per RFC 9309. Add --html for a self contained report you can hand to anyone, or --sample to try it on bundled data first.
It makes zero network calls. Your log never leaves your machine.
